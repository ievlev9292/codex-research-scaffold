# Research and durable evidence

Use the current task's scientific assumptions, scope and success criteria. Use the current run under AGENTS.md's chat-boundary rules; do not start another run mid-chat without the user's explicit request. tools/runs.py helps maintain its record and index. Ordinary and extended research share these rules. Extended requests may specify priorities, fallback approaches and attempt/resource budgets in advance; they do not automatically broaden permissions.

Before starting a substantial investigation, audit what is already known about the question. Inspect supplied literature and actively search the Internet beyond it, even when the supplied collection is extensive. The main agent chooses a proportionate search scale from the question's breadth, stakes, familiarity and available budget; a small question needs only a focused check. Identify established solutions, partial progress, relevant limits and unresolved disagreements before choosing new work. Match assumptions and conventions rather than relying on similar titles. If an existing result answers the question, explain and verify its applicability instead of automatically repeating the investigation.

Keep the audit compact: record scope, useful queries, dated coverage, key findings and the resulting research decision in the existing RUN.md, with source identities and checked locators in the catalogue. Distinguish metadata screening from reading and verification. Limited access or search coverage remains a limitation; a search with no relevant hits does not establish novelty or prove that a problem is unsolved. Refresh the audit when the question materially changes, not at every step. Follow [source acquisition](retrieval.md) when retaining papers for substantive reading.

Use a simple cost estimate to choose literature-survey execution: compare anticipated screening/reading work with delegation, context transfer and main-agent verification overhead; no separate budget dossier or invented precise pricing is needed. Keep small surveys with the main agent. For large surveys, employ a bounded subagent using gpt-5.6-sol at High effort by default; reserve gpt-5.6-terra at High for truly enormous surveys when the estimated workload justifies it. This is the default authorization for literature-survey delegation, subject to higher-priority restrictions and explicit user limits; it does not authorize unrelated delegation. Give the subagent the question, scope, search coverage and a compact evidence-return contract. The main agent checks consequential sources and integrates the findings. If the requested model/delegation is unavailable, state the limitation and use available authorized main-agent work rather than claim the specified model ran.

Before substantial downstream work, test consequential foundational assumptions. When adapting a result, establish its regime and convention mapping. Devise useful checks, consult scientific resources when needed, and actually run feasible checks within the host budget. Examples include controlled limits, residuals, symmetries, convergence, precision/seed sensitivity and independently constructed methods.

Verification must refer to the exact equation, implementation, inputs and retained output checked. State the basis for the expected result, material shared assumptions and actual pass/fail/inconclusive/not-performed outcome. A fit to its calibration data is not independent predictive validation. Preserve significant failures and investigate disagreements. A finite sample does not prove a general identity; different tools can share the same wrong assumptions.

Save meaningful progress where it belongs:
- Calculation details, check evidence and current result assessment: the calculation/derivation record.
- Shared assumptions and convention history: research/notes/.
- Run scope, decisions, task coverage, concise outcomes and evidence links: RUN.md.
- Current entry point and future questions: compact project handoff/backlog.

Use [calculation records](../calculations/README.md). Group related checks/sweeps; no per-equation dossier or second coverage table. When a foundational result changes, inspect dependent uses and mark identified affected results for recheck while preserving historical evidence. This is a scoped review, not a claim of exhaustive automatic dependency tracking.

Save after important reasoning or completed work and before costly transitions. Reuse existing files; no timer, per-tool journal or user pause. Before reporting completion or preparing a report, reconcile requested outcomes with artifacts, unresolved items and deliberate exclusions. Completing an investigation may yield a negative or conditional result. Only explicit user instruction closes the run.

If an inaccessible Internet source has concrete evidence of relevance, record its identity, obtained access, obstacle, relevance evidence and affected claim in the source catalogue. Make bounded attempts at legitimate accessible versions or alternatives, continue useful work, and report it at the next existing user checkpoint or natural update. Metadata access is not full-text inspection. Avoid repeated unchanged notices or a new approval pause.
