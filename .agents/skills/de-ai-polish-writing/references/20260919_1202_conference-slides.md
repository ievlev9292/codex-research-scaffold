# Conference slides

Read for visible scientific slide text, including titles, labels, and figure or table captions. Scope is visible content unless the user explicitly includes speaker notes or spoken narrative.

## Edit for the visual task

A slide may identify a quantity, frame a question, orient a figure, compare outcomes, or state one finding. Keep that function. Fragments, short labels, and parallel bullets can communicate it better than complete sentences. Do not turn every title into a claim or impose one grammatical pattern across a deck.

Preserve or reduce text density. Cut empty framing first. Keep necessary limitations, values, units, and scientific relationships even if the slide remains crowded. If further compression would lose meaning, retain the necessary text and briefly flag the layout constraint instead of silently deleting a caveat.

Captions need enough information to interpret the displayed figure or table: panel identities, variables, units, conditions, and what lines, symbols, or error bars mean. Keep these mappings intact. Do not expand a concise caption into manuscript prose or invent an explanation from a plot that the supplied text does not support.

## Preserve presentation structure

Keep the association between text, figures, tables, equations, and layout. Preserve slide order, figure placement, mathematical notation, references, and animation or overlay semantics unless explicitly authorized to change them. Avoid moving information to another slide or to notes as a density workaround.

For Beamer, preserve frame environments, options, overlays, commands, labels, and mathematical expressions. Edit only visible prose arguments and text nodes; leave comments and speaker-note commands untouched by default. For PowerPoint and other containers, use available presentation capabilities and keep notes, hidden content, and object relationships outside a visible-text-only edit.

Use the host's rendering or layout checks when available. Without a render, assess text length and structure conservatively and state any material verification limit rather than claiming the slide fits.

## Explicit note expansion

If the user separately includes existing speaker notes, edit those notes as spoken scientific explanation, with the same semantic safeguards. Keep note and slide edits distinct, and do not copy note material onto slides. Writing a new spoken narrative is drafting, which requires a separate task rather than this final-pass workflow.
